Tentang Saya

Nama saya Muhammad Rizky biasa dipanggil Rizky atau Muri, saya lahir pada tanggal 16 Juli 2007. Saya adalah mahasiswa Unindra Prodi Teknik Informatika yang memiliki ketertarikan terhadap dunia komputer dan pemrograman. Saya merupakan pribadi yang cenderung pendiam dan memiliki rasa ingin tahu yang tinggi terhadap hal-hal baru.

Perjalanan Saya

Ketertarikan saya terhadap pemrograman sudah muncul sebelum saya memasuki dunia perkuliahan. Setelah masuk kejurusan Teknik Informatika saya semakin tertarik untuk mempelajari bagaimana sebuah program, website, dan aplikasi dapat dibuat.

Saat ini Saya mempelajari beberapa teknologi dan bahasa pemrograman seperti Pascal, Java, HTML, CSS. Dari beberapa teknologi tersebut, saya paling suka HTML dan CSS karena saya dapat melihat secara langsung hasil dari apa yang telah saya buat.

Cara Saya Belajar

Ketika menemukan masalah atau error dalam proses belajar, saya biasanya mencoba mencari penyebabnya sendiri terlebih dahulu. Jika sudah benar-benar tidak ketemu, saya akan mencari melalui internet atau menggunakan bantuan AI.

Bagi saya, belajar tidak hanya dilakukan dengan mempelajari teori, tetapi juga dengan mempraktikannya dan mengembangkan apa yang sudah dipelajari. Saya berusaha untuk tetap konsisten belajar walaupun hanya sedikit demi sedikit.

Rencana dan Tujuan

Saya ingin meningkatkan kemampuan dalam web development hingga mampu membuat website dan aplikasi secara mandiri. Jika kemampuan saya sudah lebih berkembang, saya juga memiliki keinginan untuk membuka jasa pembuatan website atau aplikasi.

Saya juga ingin mempelajari JavaScript, Python, dan database. Selain web development, saya tertarik untuk mempelajari cyber security dan memiliki keinginan untuk mencoba membuat game tema horror atau FPS.

Prinsip Saya

Saya percaya bahwa kemampuan dapat berkembang melalui proses belajar yang konsisten dan praktik secara langsung. Rasa penasaran juga menjadi salah satu hal yang mendorong saya untuk terus belajar, terutama ketika menemukan sesuatu yang belum saya pahami.
